# Portfolio Rakia Limem — Template blanc

Portfolio React + Vite, avec un thème clair (white template) et un dossier MDW 3.2.

## Lancer le projet

1. Installer Node.js (version LTS recommandée).
2. Dans ce dossier, lancer `npm install`.
3. Lancer `npm run dev` pour le serveur local.
4. Pour générer le site de production : `npm run build`.

## Livrables MDW inclus

- Diagnostic personnel et note critique IA
- CV et lettre : versions initiale et personnalisée, comparatif
- Profil en ligne et veille avec liens vers trois annonces vérifiées le 25 novembre 2026
- Questions d'entretien et grille d'auto-évaluation (saisie manuelle; données conservées localement dans le navigateur)

## À finaliser par l'étudiante (preuves qui ne peuvent pas être fabriquées)

- Capturer les pages des offres d'emploi (capture avec titre, entreprise, date et technologies) et les conserver pour le dossier remis à l'enseignant.
- Enregistrer sa propre simulation d'entretien, héberger la vidéo avec accès autorisé et coller son lien dans le champ du portfolio.
- Compléter l'auto-évaluation après visionnage.
- Vérifier l'exactitude de toutes les expériences, coordonnées et projets décrits; ne garder que les éléments réels et prouvables.
- Exporter et ajouter les fichiers PDF finaux du CV et de la lettre de motivation si l'enseignant demande les documents téléchargeables.

Trois rapports PDF sont disponibles dans le dossier Dossier MDW : diagnostic personnel, veille professionnelle et comparaison CV/lettre. Les fiches d’offres sont des synthèses reconstituées, pas des captures originales; vérifier les sources et ajouter des captures authentiques. La vidéo d’entretien personnelle n’est pas incluse.

## Notes de vérification

- Les champs du lien vidéo et de l'auto-évaluation sont enregistrés dans le navigateur utilisé (localStorage); ils ne se synchronisent pas avec le navigateur de l'enseignant. Pour que le lien soit visible sur la version publiée, ajoute le lien vidéo dans le code avant de redéployer.
- Les annonces ont été vérifiées le 25 novembre 2026. Leur disponibilité peut changer; conserve des captures d'écran datées comme preuves de veille.
- Les expériences, résultats chiffrés, projets et coordonnées sont des données de portfolio à confirmer par la propriétaire avant diffusion.
- Le build n'a pas pu être testé dans cet environnement, car les dépendances npm ne sont pas disponibles et l'installation a échoué faute d'accès au cache/réseau. Lance `npm install` puis `npm run build` sur ta machine.

## CV et lettres — aperçu professionnel / export PDF

Les quatre documents du Livrable 2 (CV initial IA, CV final, lettre initiale IA et lettre personnalisée) disposent désormais d'une mise en page dédiée. Ouvrir le document depuis la section Dossier MDW puis utiliser **Imprimer / PDF** pour enregistrer le document en PDF. Dans la boîte d'impression, choisir le format **A4** et activer l'impression des arrière-plans/couleurs si le navigateur le propose.
